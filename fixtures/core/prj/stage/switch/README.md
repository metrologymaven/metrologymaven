# CORE.PRJ.STAGE.SWITCH fixtures

Project-made test data, CC-BY-4.0. Generated by `make_fixtures.py` (Python standard library
only, independent of the Rust code); `python fixtures/core/prj/stage/switch/make_fixtures.py --check`
fails if a committed file is stale.

- `p3s/setup.json`: namespace, reserved IDs, run, stage and element IDs, test element type.
- `p3s/events.jsonl`: project p3s: 3 stages, 50 elements, every slot `current` with a
  distinct value.
- `p3s/values.json`: slot digest to value text; each digest is the SHA-256 of the value bytes.
- `p3s/expected_digest.txt`: the canonical state digest of p3s.
- `cases.json`: AC-1 (switch to S2), AC-3 refusals, AC-5 journal digest.

See the generator's docstring for the pinned event, state and result forms.
