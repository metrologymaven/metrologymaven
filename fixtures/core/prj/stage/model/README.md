# CORE.PRJ.STAGE.MODEL fixtures

Project-made test data, CC-BY-4.0. Generated by `make_fixtures.py` (Python standard library
only, independent of the Rust code); `python fixtures/core/prj/stage/model/make_fixtures.py --check`
fails if a committed file is stale.

- `p100/setup.json`: the project namespace, reserved IDs, container and stage IDs, the 100
  element IDs, the principal and the test element type.
- `p100/events.jsonl`: the synthetic project p100 (100 elements, one stage S1 that took the
  implicit default stage's place and data), one canonical event per line.
- `p100/expected_digest.txt`: the canonical state digest of p100.
- `cases.json`: AC-1 (add S2), a drawn-ID add, AC-2 (S2 .. S1000), AC-3 (soft remove, list,
  undo, refusals), AC-4 (reorder and its refusals) and hand-labelled add and list refusals,
  with expected events, results, bus errors and state and per-stage digests.

See the generator's docstring for the pinned event, state and result forms.
