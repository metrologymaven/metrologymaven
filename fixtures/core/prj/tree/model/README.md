Project-made test data, CC-BY-4.0. Generated by `make_fixtures.py` (Python standard library
only, independent of the Rust code); `python fixtures/core/prj/tree/model/make_fixtures.py --check`
fails if a committed file is stale.

- `setup.json`: the project namespace, the reserved root group and default stage IDs, and the
  three test element types.
- `events.jsonl` (AC-1): 200 core events over 50 elements of 3 test types.
- `expected_digest.txt` (AC-1): the canonical state digest after applying `events.jsonl`.
- `transitions.csv` (AC-2): all 16 state pairs, hand-labelled from REQ-003.

See the generator's docstring for the pinned event and state forms.
