# CORE.DEP.PROP propagation cases (hand-labelled from the leaf's Design rules; CC-BY-4.0).
# Every expected line below was written by hand. make_prop_fixtures.py --check re-derives
# each case with a separate stdlib reference and fails on any difference.
#
# `elem <name> <id>` names an element for all cases (c < b on purpose; z is never in a graph).
# A case runs from `case <name>` to `end`:
#   edge <input> <element>     an edge input -> element (both become known)
#   state <name> <state>       current | outdated | failed | not_computed
#   changed <names...>         elements the commit changed
#   recomputed <names...>      elements the commit recomputed in this pass
#   mode auto | manual
# Expected, for a pass that succeeds:
#   order <names...>           region in propagation order (topological, ties by ascending ID)
#   pending <names...>         stale elements, propagation order
#   marked <names...>          elements moved to outdated, propagation order
#   event <names...>           the dep.elements_marked@1 list, ascending ID (bare `event`: no event)
#   submit <names...>          the recompute submitted after the commit, ascending ID (bare: none)
# Expected, for a pass that is refused (nothing changes):
#   error <code> <reason> <names...>
