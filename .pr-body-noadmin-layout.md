## Deviations and judgement calls (stated openly)

1. **Extra error variants** beyond the Design's `Parse, UnknownVariable, OutsideProfile, MissingOs, TooLarge`: `UnsupportedSchema`, `BadField` (structure), `BadTemplate` (malformed template, or a variable not allowed for that entry), `MissingRegistration` (REQ-003 needs all four names). Expansion has its own `ExpandError` (`MissingOs`, `Unset`, `BadValue`, `OutsideProfile`).
2. **Static template rules for REQ-004:** a template must start with a variable; a literal path or a `..` segment is `OutsideProfile`. Windows `install_dir` must start with `{local_app_data}`, others with `{home}` (REQ-001); another variable there is also `OutsideProfile`. `allowed_writes` may start only with the per-user data/cache/config dirs (Windows `{local_app_data}`/`{app_data}`, macOS `{home}` for `~/Library/...`, Linux `{xdg_*}`) plus `{tmp}`, `{project_roots}`, `{export_roots}` (REQ-002). Variables not defined on the OS (e.g. `xdg_*` on Windows) are `UnknownVariable`. `expand` re-checks every expanded path against home/tmp/roots, so e.g. `XDG_DATA_HOME=/data/xdg` or a roaming profile redirected to a file server fails with `OutsideProfile` at expansion time (the spec's literal rule; may be too strict for redirected profiles; for AUDIT to settle).
3. **Env:** the Design's `Env` trait is `path(var)` + `roots(var)` (project/export roots are lists). `resolve_env(os, lookup, roots...)` derives values from raw env vars through an injected lookup: Windows `USERPROFILE`, `LOCALAPPDATA`/`APPDATA` (fallback `{home}\AppData\Local|Roaming`), `TEMP`/`TMP`; macOS `HOME`, `TMPDIR` (fallback `/tmp`); Linux `HOME`, `XDG_*_HOME` with the XDG Base Directory fallbacks, `TMPDIR`. Empty means unset; relative values are errors, except `XDG_*`, which the XDG spec says to ignore (fallback applies). No OS known-folder API is called (no `unsafe`, no new dependency); callers that read known folders build a `MapEnv`.
4. **Path normalisation:** `..` is rejected, never resolved. On Windows also rejected: drive-relative `C:x`, `\\?\` / `\\.\`, `:` in a segment (alternate data streams), segments ending in `.` or space. macOS comparison is case-insensitive via Unicode lower case; NFD normalisation is not applied. A support-matrix row has no desktop/server field in schema 1, so every effective Tier 1 row counts as a desktop row.
5. **macOS preferences:** the proposal says `~/Library/Preferences` "app's own domain only"; a prefix rule cannot express a domain, so the file lists `{home}/Library/Preferences/Fiducial.plist` as a **placeholder** until ECO.REL.PKG.MAC fixes the bundle identifier. "Fiducial" is the D-002 working name.
6. Added a CI step to `rust.yml` (same pattern as PLAT.GPU.POLICY) for AC-1/2/4 through `cargo xtask`. No permissions or gates changed.
