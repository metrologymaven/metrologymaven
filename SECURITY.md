# Security Policy

**Status (pre-alpha):** Metrology Maven has no released versions yet. No build in this repository is currently supported for production use.

## Reporting a vulnerability

**Do not open a public GitHub issue for a security vulnerability.**

Please report suspected vulnerabilities privately by email to **hello@metrologymaven.io** with:

- a description of the issue and the affected crate, tool or workflow;
- reproduction steps or a minimal proof-of-concept input;
- any suggested fix or mitigation, if you have one.

We aim to acknowledge reports within 3 working days and provide an initial assessment within 10 working days (targets provisional while pre-alpha; see `spec/qual/vuln/policy/NODE.md`).

## Safe harbour

Good-faith security research and responsible disclosure conducted against local copies of this open-source software are welcome. Please avoid accessing other users' data or disrupting hosted services.
