# KRN.NUM.RNG: Counter-based random number generator

## Purpose

The only source of randomness in the kernel. A counter-based generator addressed by (seed, stream, index) gives the same number on every target and at any thread count, so multi-start, RANSAC, Welzl shuffles and Monte Carlo replay exactly from a journaled seed.

## Scope

**In:** Philox4x32-10 block function; u64, uniform f64 in [0, 1) and bounded-integer draws; a deterministic Fisher-Yates shuffle; stream derivation for sub-tasks.
**Out:** sampling distributions for uncertainty (`UNC`); choosing seeds and journaling them (the caller and `CORE`).

## Requirements

- **REQ-KRN.NUM.RNG-001** The generator shall compute output `index` of stream `stream` under key `seed` with the Philox4x32-10 block function, with no hidden state between calls.
- **REQ-KRN.NUM.RNG-002** `uniform_f64` shall map the top 53 bits of a u64 draw to [0, 1) by exact multiplication by 2^-53.
- **REQ-KRN.NUM.RNG-003** `below(n)` shall return a uniformly distributed integer in [0, n) by rejection sampling whose retries consume the next indices of the same stream, and shall return `NumError::Domain` for n = 0.
- **REQ-KRN.NUM.RNG-004** `shuffle` shall apply Fisher-Yates from the last element down, drawing with `below`, so a given (seed, stream, start index) always gives the same permutation.
- **REQ-KRN.NUM.RNG-005** For the same address, every output shall be bit-identical on x86-64, ARM64 and wasm32.

## Acceptance criteria

- **AC-1** Given fixture `fixtures/num/rng-philox-kat-v1` (known-answer vectors for Philox4x32-10 regenerated from the published reference implementation), when the block function runs, then every output word matches.
- **AC-2** Given seed 0x0123456789ABCDEF, stream 7, indices 0..10^6, when `uniform_f64` runs on x86-64, ARM64 and wasm32, then the SHA-256 of the output bit patterns is identical and equals the golden digest in `fixtures/num/rng-stream-v1`.
- **AC-3** Given `shuffle` of 0..1000 with the same address twice, then both permutations are identical; with stream 8, the permutation differs.
- **AC-4** (error path) Given `below(0)`, then it returns `Domain`.
- **AC-5** Given 10^6 draws of `below(10)`, then a chi-square test against uniform passes at alpha = 0.001.

## Design

- **Registry command(s):** none; module `fid_num::rng`.
- **Data structures:** `pub struct Address { seed: u64, stream: u64 }`; `pub struct Cursor { addr: Address, index: u64 }` (plain value, `Copy`); functions `block(seed, stream, counter) -> [u32; 4]`, `Cursor::next_u64`, `uniform_f64`, `below`, `shuffle<T>(&mut [T], &mut Cursor)`.
- **Algorithm:** Philox4x32-10 (Salmon, Moraes, Dror, Shaw, "Parallel random numbers: as easy as 1, 2, 3", SC 2011); the 128-bit counter is (index low, index high, stream low, stream high), the 64-bit key is the seed. Two u32 words make one u64.
- **Errors:** `Domain` for `below(0)`.
- **Determinism:** D0 (integer arithmetic only).
- **Performance budget:** 10^7 u64 draws < 100 ms on reference hardware [unverified until measured].
- **Crate:** `fid-num` (module `rng`).

## Build prompt

> In crate `fid-num`, create module `rng` implementing Philox4x32-10 as a pure function `block(seed: u64, stream: u64, counter: u64) -> [u32; 4]` (counter words = index lo/hi, stream lo/hi; key = seed lo/hi; 10 rounds with the standard Philox multipliers and Weyl key increments). Add `Cursor { seed, stream, index }` with `next_u64`, `uniform_f64` (top 53 bits * 2^-53), `below(n)` (rejection sampling using following indices; `NumError::Domain` for n = 0) and `shuffle<T>(&mut [T], &mut Cursor)` (Fisher-Yates from the end). No global or thread-local state. Tests: known-answer vectors `fixtures/num/rng-philox-kat-v1`; golden SHA-256 over 10^6 `uniform_f64` outputs for seed 0x0123456789ABCDEF stream 7 on x86-64, ARM64 and wasm32 under wasmtime; shuffle reproducibility; chi-square uniformity. KNP-1: integer ops only, no `unsafe`, no I/O, no HashMap/HashSet; deny `unwrap`/`expect`/`panic`. Acceptance: AC-1..AC-5 of spec node KRN.NUM.RNG.
