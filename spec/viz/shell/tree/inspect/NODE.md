# VIZ.SHELL.TREE.INSPECT: Inspector property grid

## Purpose

The property grid for the selected element: read-only fields from the entity schema (values of record shown only as kernel-formatted strings with a provenance badge) and editable fields whose editors are generated from the schema of the command that changes them, with explicit SI units. Committing a field submits that command; the inspector never edits state directly.

## Scope

**In:** inspector panel `viz.inspector`; field list from entity schemas annotated with their edit command; editors from `VIZ.SHELL.PALETTE.FORMS`; provenance badges (algorithm ID, evaluation basis, UEC level) on values of record; untrusted text fields; multi-selection showing common fields.
**Out:** form generation (`VIZ.SHELL.PALETTE.FORMS`); provenance detail view (`VIZ.SHELL.TREE.WHY`); kernel formatting (`KRN.NUM.FMT`).

## Requirements

- **REQ-VIZ.SHELL.TREE.INSPECT-001** Committing an edited field shall submit the field's declared edit command through `ShellBus`, and fields with no declared edit command shall be read-only.
- **REQ-VIZ.SHELL.TREE.INSPECT-002** Every numeric field shall show its SI unit, and editors shall be generated from the edit command's schema.
- **REQ-VIZ.SHELL.TREE.INSPECT-003** Values of record shall be displayed only as the kernel-formatted string supplied with the record, with a provenance badge showing evaluation basis and UEC level, and the node shall have role `value_of_record` with `basis` and `entity_id` attributes and a "Why?" action.
- **REQ-VIZ.SHELL.TREE.INSPECT-004** Text fields holding content strings shall be displayed and edited as untrusted plain text.

## Acceptance criteria

- **AC-1** Given fixture `fixtures/viz/scene-doc-small` and a selected characteristic, when its nominal is edited to `10.000 mm`, then one registry command with the decimal string and unit is journaled.
- **AC-2** Given a measured value of record, then the field shows the kernel string byte-for-byte, a badge with basis and UEC, and the inspection node has role `value_of_record` and a Why? action with its `command` attribute.
- **AC-3** Given a field without an edit command, then no editor appears.
- **AC-4** Given two selected characteristics, then only common fields are shown and an edit submits one command per element (or the batch command where declared).

## Design

- **Registry command(s):** none of its own.
- **Data structures:** `InspectorField { path, label: MessageId, value: Display, edit: Option<CommandId> }`; `ProvenanceBadge { basis, uec, algorithm }`.
- **Errors:** bus validation errors shown inline.
- **Determinism:** D0 (field model).
- **Performance budget:** 200 fields under 2 ms per frame.
- **Crate:** `fid-shell` (module `tree::inspect`).
