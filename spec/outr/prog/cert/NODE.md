# OUTR.PROG.CERT: User training and certification program

## Purpose

A curriculum and certification ladder (for example operator, programmer, inspector, expert) so that users can prove competence the way incumbents' certified-programmer programs do. Exams are built on published example projects and graded from journals, so they are reproducible and can run without an instructor.

## Scope

**In:**
- Curriculum and levels mapped to the FLOW acceptance jobs
- Exercises built on published example projects and golden journals
- Exam format and journal-based grading
- Certificate records and a public verification page
- Instructor kit for training partners

**Out:**
- Commercial terms, pricing and contracts (business documents outside the tree)

## Requirements

- **REQ-OUTR.PROG.CERT-001** The project shall run a user training and certification program (curriculum, hands-on exercises on published example projects, proctored or reproducible exams) whose levels map to the acceptance jobs.
