# PLAT.DEPLOY.NOADMIN.ALLOW: Allow-listing guide

## Purpose

Gives an IT administrator what an application allow-listing tool needs: per Tier 1 OS, the per-user and machine-wide install paths, the executable names, and the publisher identity the binaries are signed with. The page is generated from the layout file and the signing identity file, so it cannot drift.

## Scope

**In:**
- `docs/deploy/allow-listing.md`, generated by `xtask plat-deploy allow-doc`
- A drift check that regenerates the page and fails on difference

**Out** (and which node owns it instead):
- Code signing and the identity values (`ECO.REL.SIGN.OSSIGN`)
- Install paths (`PLAT.DEPLOY.NOADMIN.LAYOUT`)

## Requirements

- **REQ-PLAT.DEPLOY.NOADMIN.ALLOW-001** The generated page shall list, per Tier 1 OS family, the expanded per-user install path pattern, the executable file names of every app, `fid` and `fid-verify`, and the publisher identity string the binaries are signed with.
- **REQ-PLAT.DEPLOY.NOADMIN.ALLOW-002** If the signing identity file lacks an identity for an OS family listed in the layout, then generation shall fail naming the OS family.
- **REQ-PLAT.DEPLOY.NOADMIN.ALLOW-003** CI shall fail if the committed page differs from a fresh generation.
- **REQ-PLAT.DEPLOY.NOADMIN.ALLOW-004** The page shall begin with "Generated by fid-xtask plat-deploy allow-doc. Do not edit." and the SHA-256 of both input files.

## Acceptance criteria

- **AC-1** Given `fixtures/plat/deploy/layout-valid.toml`, `fixtures/plat/deploy/signing-identities.toml` and the executable list `fixtures/plat/deploy/executables.toml`, when the generator runs, then the output equals `fixtures/plat/deploy/allow-listing.md` byte for byte.
- **AC-2** (error path) Given an identity file without macOS, then it exits 1 with `MissingIdentity { os: macos }`.
- **AC-3** Given a committed page edited by hand, when the drift check runs, then it fails.

## Design

- **Registry command(s):** none; `xtask plat-deploy allow-doc [--check]`.
- **Data structures:** reads `PeruserLayout`; `SigningIdentities { os: BTreeMap<OsFamily, String> }` (format published by `ECO.REL.SIGN.OSSIGN`; fixture shape until it publishes one); executable names from the app list.
- **Errors:** `MissingIdentity`, input parse errors passed through.
- **Determinism:** D0.
- **Crate:** `xtask` (module `plat_deploy_allow`).
