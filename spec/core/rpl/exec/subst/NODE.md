# CORE.RPL.EXEC.SUBST: Observation substitution and missing-item detection

## Purpose

Makes a replay see exactly what the recording saw. Every class-N input (instrument data, wall clock readings, human-entered text, LLM output, external file contents, CSPRNG salts) is served from the record by digest through an `ObservationSource`, so nothing is regenerated. Before a replay starts, SUBST also checks that every blob, command major and kernel the span needs is available, and names each missing item so the step can be reported `NOT_REPLAYABLE`.

## Scope

**In:** the `ObservationSource` implementation over a recorded span, observation kinds, digest checks, the pre-flight availability scan, typed missing-item records.
**Out:** how handlers read observations (they call the bus's observation port, `CORE.BUS.PIPE`); kernel artifact lookup (`CORE.RPL.EXEC.VERIFY` supplies a `KernelSource` this leaf queries); classification (`CORE.RPL.CLASS`).

## Requirements

- **REQ-CORE.RPL.EXEC.SUBST-001** When a replayed handler requests a class-N observation, the source shall return the recorded value whose digest the entry holds, and shall never call a clock, random generator, device, LLM or file system for it.
- **REQ-CORE.RPL.EXEC.SUBST-002** When a replayed handler requests more observations, or a different kind, than the recording holds for that step, the source shall return `observation_mismatch` and the step shall be classified `DIVERGENT` with cause `input`.
- **REQ-CORE.RPL.EXEC.SUBST-003** When a recorded observation blob is read, the source shall verify its SHA-256 against the recorded digest, and if the blob is absent or fails the check, then it shall report the step `NOT_REPLAYABLE` naming the digest.
- **REQ-CORE.RPL.EXEC.SUBST-004** Commitment salts shall be served from the entry payload as class-N observations so that re-computed header commitments equal the recorded ones.
- **REQ-CORE.RPL.EXEC.SUBST-005** Before the first step, the pre-flight scan shall list every missing blob digest, every command major that is neither retained nor reachable by migrators, every detached payload, and every kernel digest the `KernelSource` cannot supply.
- **REQ-CORE.RPL.EXEC.SUBST-006** Each missing item shall be reported with its kind (`blob`, `command`, `payload`, `kernel`), its identifier and the sequence numbers of the steps that need it.

## Acceptance criteria

- **AC-1** Given fixture `fixtures/core/rpl/exec/subst/clock_and_salt` (entries whose handlers read the clock and draw salts), when replayed with a clock and RNG that panic if called, then every step is `IDENTICAL` and neither is called.
- **AC-2** Given `fixtures/core/rpl/exec/subst/device_read` (an I1 simulator read recorded as an observation blob), when replayed, then the recorded blob is served and the step is `IDENTICAL`.
- **AC-3** (error path) Given the same fixture with the observation blob deleted from the store, then the pre-flight scan names `blob` with that digest and the step is `NOT_REPLAYABLE`.
- **AC-4** (error path) Given an entry whose command major is removed with no migrator, then the scan names `command` with ID and major.
- **AC-5** (error path) Given a handler changed to read two clock values where the recording has one, then the step is `DIVERGENT` with cause `input`.

## Design

- **Registry command(s):** none; library.
- **Data structures:** `ObservationKind { Clock, Salt, Device, HumanText, LlmOutput, ExternalFile, Other(String) }`; `RecordedObservations` per step as an ordered list of `(kind, digest, inline_or_blob)`; `MissingItem { kind, id, steps: Vec<u64> }`; `trait KernelSource { fn has(&self, digest) -> bool; }`.
- **Algorithm:** per step, a queue of recorded observations consumed in order; mismatch on kind or exhaustion; pre-flight walks the span once collecting needed blobs, majors, payload presence and kernel digests into ordered sets.
- **Errors:** `observation_mismatch`, `missing_item`.
- **Determinism:** D0.
- **Performance budget:** pre-flight over 10,000 entries in < 500 ms [unverified until measured].
- **Crate:** `fid-replay` (module `subst`).
