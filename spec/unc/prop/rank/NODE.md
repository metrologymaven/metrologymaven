# UNC.PROP.RANK: Contributor ranking

## Purpose

Ranks the input quantities of an evaluated model by how much each contributes to the output uncertainty, so that explanations, reports and agents can name the largest contributors. For LPU results it uses sensitivities; for MCM-only results it uses an approximate sample-based measure and says so.

## Scope

**In:**
- LPU ranking: |c_i|·u(x_i) and the correlation-aware (Euler) share c_i·(Σc)_i / u_c²
- MCM ranking: squared Pearson correlation between each input's samples and the output samples, labelled `approximate`
- Output as the `contributors` list of the statement

**Out:**
- Computing sensitivities and samples (owned by `UNC.PROP.LPU` and `UNC.PROP.MCM`)
- Displaying them (owned by `UNC.UEC.EXPL`)

## Requirements

- **REQ-UNC.PROP.RANK-001** Given LPU sensitivities c and input covariance Σ, the function shall return for each input u_i(y) = |c_i|·√Σ_ii and the share c_i·(Σc)_i / (cᵀΣc), with shares summing to 1 within 1e-12.
- **REQ-UNC.PROP.RANK-002** Given only Monte Carlo input and output sample sets, the function shall return for each input the squared Pearson correlation with the output, computed with fixed-order reductions, and set `method = approximate_src2`.
- **REQ-UNC.PROP.RANK-003** The returned list shall be sorted by descending u_i(y) (LPU) or squared correlation (MCM), ties broken by input ID.
- **REQ-UNC.PROP.RANK-004** If cᵀΣc is zero or the output sample variance is zero, then the function shall return the contributors with shares absent and flag `degenerate`, never dividing by zero.

## Acceptance criteria

- **AC-1** Given `fixtures/unc/rank/lpu_3in.json` (c = (1, 2, −1), independent u = (0.1, 0.05, 0.2)), when ranked, then the order is x3, x1/x2 tie broken by ID, the shares are (0.01, 0.01, 0.04)/0.06 within 1e-15, and they sum to 1.
- **AC-2** Given `fixtures/unc/rank/lpu_corr.json` (two inputs with ρ = −0.9), when ranked, then the shares match the 50-digit reference in the fixture within 1e-14 and sum to 1.
- **AC-3** Given `fixtures/unc/rank/mcm_samples.bin` (10^5 trials of Y = X1 + 3·X2 with seed `0x52414E4B`), when ranked by samples, then X2 ranks first and `method = approximate_src2`.
- **AC-4** (degenerate) Given all sensitivities zero, then shares are absent and `degenerate` is set.
- **AC-5** (portability) Given AC-1..3, outputs are bit-identical on wasm32, x86-64 and ARM64.
- **AC-H1** Hypothesis: LPU contributor ranking reproduces the order and magnitudes of the published uncertainty budget of the JCGM 100:2008 end-gauge example (H.1 [unverified: annex numbering]), with agreement to the number of significant digits the guide publishes (at most one unit in the last published digit) for each |c_i| u(x_i), measured by comparing the ranked list with the published budget; falsified if the order or any magnitude disagrees.
- **AC-H2** Hypothesis: the `approximate_src2` ranking agrees with the LPU ranking with Kendall tau ≥ 0.9 [unverified] on every case of the JCGM 101:2008 worked examples (additive model, mass calibration, comparison loss, gauge-block calibration [unverified: clause 9 numbering]), encoded from their published input definitions with the published results as reference values where `UNC.PROP.VALID` returns `validated = true`, measured from 10^6-trial sample sets; falsified if any such case is below 0.9. Cases with `validated = false` are reported but not scored.

## Design

- **Registry command(s):** none; kernel algorithm `unc.prop.rank@1.0.0` called by `UNC.PROP.SELECT`.
- **Data structures:** input `RankInput::Lpu { c: Vec<f64>, cov: SymMatrix, ids } | RankInput::Samples { inputs: Vec<SampleRef>, output: SampleRef, ids }`; output `Vec<Contributor>` plus `method` and `flags`.
- **Algorithm:** fixed-order dot products from `fid-num`; stable sort by key then ID.
- **Errors:** `dimension_mismatch`, numeric errors from `fid-num`.
- **Determinism:** D0.
- **Performance budget:** 1,000 inputs × 10^5 samples in under 1 s [unverified until measured].
- **Crate:** `fid-kunc`.
