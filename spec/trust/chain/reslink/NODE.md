# TRUST.CHAIN.RESLINK: ResultRecord to journal linkage

## Purpose

Ties each packaged result to the evidence chain: every ResultRecord carries a journal entry hash (CONSTITUTION §5), and that hash must be one of the entries the chain walk verified. A result that points outside the verified segment is reported `UNLINKED`, because nothing in the package proves how it was produced.

## Scope

**In:**
- Reading `results/records.json` via the package reader
- Membership test of each record's journal entry hash against the verified hash set
- `LINKED | UNLINKED` per record, plus a check that the linked entry's command ID is a result-producing command

**Out:**
- Walking the chain (`TRUST.CHAIN.LINKS`)
- Recomputing results (`TRUST.REPLAY`)

## Requirements

- **REQ-TRUST.CHAIN.RESLINK-001** The linker shall report each ResultRecord whose journal entry hash is not in the verified segment as `UNLINKED` with its record ID.
- **REQ-TRUST.CHAIN.RESLINK-002** When the chain verdict is `BROKEN`, the linker shall treat only entries before the first failing index as verified.
- **REQ-TRUST.CHAIN.RESLINK-003** If a record links to an entry whose output digests do not include the record's digest, then the linker shall report `MISLINKED` with record ID and entry index.

## Acceptance criteria

- **AC-1** Given `fixtures/pkg/golden/points.zip`, then every record is `LINKED`.
- **AC-2** (error path) Given `fixtures/chain/reslink/foreign-hash.zip` (one record's hash replaced by a random digest), then exactly that record is `UNLINKED`.
- **AC-3** (error path) Given `fixtures/chain/reslink/broken-at-5.zip` with a record linked to entry 9, then that record is `UNLINKED`.
- **AC-4** (error path) Given `fixtures/chain/reslink/wrong-entry.zip` (record linked to a valid but unrelated entry), then `MISLINKED`.

## Design

- **Registry command(s):** none; called by `verify.check_chain@1`.
- **Data structures:** `LinkResult { record_id, status: LINKED | UNLINKED | MISLINKED, entry_index: Option<u64> }`.
- **Algorithm:** binary search in the sorted `(hash, index)` vector from LINKS; output-digest check against the entry header's output digests.
- **Errors:** passthrough `pkg.*`.
- **Determinism:** D0.
- **Performance budget:** 1,000,000 records in under 2 s [unverified until measured].
- **Crate:** `fid-chain` (module `reslink`).
