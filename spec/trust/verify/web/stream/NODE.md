# TRUST.VERIFY.WEB.STREAM: Browser file-API package source

## Purpose

A `ByteSource` over a browser `File` (a `Blob`) that reads by `slice()` on demand, so the package reader can check a multi-gigabyte Result Package without loading it into memory. It also reports progress to the page.

## Scope

**In:**
- `BlobSource` implementing the async `ByteSource` with `Blob.slice` reads
- A small read-ahead window and an LRU of at most a few chunks
- Progress callbacks (bytes read of total)

**Out:**
- Package parsing and limits (`TRUST.PKG.READER`)
- The page and drop handling (`TRUST.VERIFY.WEB.SHELL`)

## Requirements

- **REQ-TRUST.VERIFY.WEB.STREAM-001** The source shall read only the byte ranges the reader requests, via `Blob.slice`, and shall hold at most 64 MiB of package bytes in memory at any time [unverified: browser limits].
- **REQ-TRUST.VERIFY.WEB.STREAM-002** Verifying (without replay) a 2 GiB golden-structure package shall complete in a headless Chromium and Firefox with peak tab memory under 512 MiB [unverified until measured].
- **REQ-TRUST.VERIFY.WEB.STREAM-003** If a slice read fails or returns fewer bytes than requested before end of file, then the source shall return `SrcErr::Io` and the report shall end with the CLI's I/O error code.
- **REQ-TRUST.VERIFY.WEB.STREAM-004** The source shall report progress at least once per 16 MiB read.

## Acceptance criteria

- **AC-1** Given a 2 GiB package generated by the fixture generator (large stored point member), when verified in headless Chromium and Firefox, then the report equals the CLI's and peak memory is under 512 MiB.
- **AC-2** (error path) Given a `Blob` double that fails at offset 1 GiB, then the result is the CLI I/O error code and no trap.
- **AC-3** Given AC-1, then progress events arrive with non-decreasing values ending at the file size.

## Design

- **Registry command(s):** none.
- **Data structures:** `BlobSource { blob: web_sys::Blob, cache: SmallLru<ChunkIdx, Bytes> }`, chunk 8 MiB.
- **Algorithm:** map `read_at` to chunk reads via `blob.slice(start, end).array_buffer()`; LRU of 8 chunks.
- **Errors:** `SrcErr::Io`.
- **Determinism:** D0.
- **Performance budget:** see REQ-002.
- **Crate:** `fid-verify-web`, module `stream`.

## Test fixtures

A 2 GiB package produced at test time by the `TRUST.PKG.FIXTURE` generator with a fixed seed (not stored in the repository).
